# Snipping Lite

Snipping Lite is a native Windows screenshot utility. Start the release build with `pwsh -File scripts/run-latest.ps1` or run `scripts/build.cmd` for a debug build. Keep it running to use **Alt+Shift+S**. The settings window opens in its own process (built with egui) and closing it leaves Snipping Lite in the notification area; use the tray menu to reopen settings or exit. The settings window needs about 70 MB while it is open; the tray process itself stays small.

The screen freezes and dims while you snip. Select rectangle, freeform, window, or full-screen capture in the toolbar at the top of the screen; the last mode is kept until the app exits. Press Escape to cancel. After a capture, a notification with a preview appears in the lower-right corner; select it to open the saved file. Settings can automatically copy captures to the clipboard and/or save PNG files to `Pictures\Screenshots`. Enable "Choose a file name when saving" to pick the name and PNG or BMP format in a Save As dialog. A capture delay of 3, 5, or 10 seconds hides the window before the toolbar appears. At least one destination must be enabled. Every capture is also kept in a history (the newest 50, 100, 200, or 500 as chosen in settings, stored in `%LOCALAPPDATA%\Snipping Lite\history`) that you can browse from the tray menu or the settings window: filter the gallery by date range or search it by date, open a screenshot to copy it again, save it as a file, show it in its folder, or delete it, and clear the whole history at once. In an opened screenshot, the pen and highlighter draw on the image; "Save changes" writes the marks into the stored image, and Copy and Save as include them. Turn "Keep a history of screenshots" off in settings to stop recording; screenshots can contain sensitive information, so clear the history when you no longer need it. A shortcut conflict is shown in the settings window.

The toolbar and notification follow the Windows 11 Snipping Tool style, including the light or dark app theme. The settings window imitates the Windows 11 settings style (toggles, cards, the system theme, and the Mica backdrop on Windows 11 22H2 or later) but is not a pixel-exact copy; tooltips and screen recording are not implemented, and annotation is only available for screenshots opened from the history. The outside of a freeform capture is transparent in PNG files and in applications that read transparency from the clipboard, and white elsewhere (including BMP files).
