# Snipping Lite

Snipping Lite is a native Windows screenshot utility. Its icon combines a blue capture frame with red and blue scissors. Start the release build with `pwsh -File scripts/run-latest.ps1`. `scripts/build.cmd` only builds the debug binary and does not start it. It starts in the notification area without opening a window; keep it running to use **Alt+Shift+S**. Open settings from the tray menu or the capture toolbar gear. Settings and history both show "Snipping Lite" in the title bar. The settings window opens in its own process (built with egui) and closing it leaves Snipping Lite in the notification area; use the tray menu to reopen settings or exit. The settings window needs about 70 MB while it is open; the tray process itself stays small.

The screen stays live while you snip, so videos and apps keep running and only the selection outline is drawn; turn on "切り取り中に画面を暗くして静止する" (dim and freeze the screen while snipping) in settings to freeze and dim it instead. Select screenshot or video in the toolbar at the top of the screen; the area dropdown selects rectangle, freeform, window, or full-screen capture for either type; the last mode is kept until the app exits. Press Escape to cancel, or use the gear button to open settings. Drag an empty part of the toolbar to move it; it returns to the top center the next time it opens. Turn on "撮影後もツールバーを表示したままにする" (keep the toolbar open after a snip) to keep the toolbar on the screen after each screenshot or recording, where its buttons start the next snip; it stays where you moved it until you close it with ×. The video button in the toolbar records the selected area to an MP4 file in the Videos folder's "画面録画" (Screen Recordings) folder, the same default as the Windows Snipping Tool (H.264, 60 fps by default with a 30 fps option, optional mouse cursor, optional AAC audio). Turn off "録画にマウスカーソルを含める" (include the mouse cursor in recordings) to omit the pointer, and choose 30 or 60 fps under "録画のフレームレート" (recording frame rate). Turn on "録画にマイク入力を含める" (include microphone input in recordings) to add the default microphone, and turn "録画にシステム オーディオを含める" (include system audio in recordings) on or off for the sound that plays on the PC. When a window is recorded, only the sound of that window's app (including the processes it started, such as a browser's audio process) is recorded; turn off "ウィンドウ録画ではそのアプリの音だけを録音する" (record only the sound of the window's app) to record all system audio instead. A microphone or device that cannot be opened is left out silently. Actual throughput depends on the capture size and available processing capacity. Window screenshots and recordings capture the selected window itself, so overlapping windows are excluded and recordings follow it when moved. Window recordings keep their initial pixel dimensions; resizing crops larger content or pads smaller content with black, and closing or minimizing the target ends the recording. Choose Window in the area dropdown and click a window to record it; "ウィンドウを録画するときタイトルバーを含めない" (leave out the title bar when recording a window, on by default) trims its title bar. Freeform videos use the shape's rectangular bounds and fill the area outside the shape with black, since H.264 does not support transparency. After the selection a 3, 2, 1 countdown runs (turn "録画前にカウントダウンする" (countdown before recording) off in settings; click the countdown to cancel). A red frame outlines the area and a small indicator with the elapsed time appears at the top of the screen; neither is part of the video; select its Stop button, press the shortcut again, click the tray icon, or choose "録画を停止" (stop recording) in the tray menu to finish, and the notification opens the file. After a capture, a notification appears in the lower-right corner (turn "通知を表示する" (show notifications) off in settings to hide it for screenshots and recordings); select "マークアップと共有" (markup and share) to open the newest screenshot in the history editor, or "開く" (open) to open the saved file when history is off. The toolbar also provides editor and history buttons. Settings can automatically copy captures to the clipboard and/or save PNG files to the Pictures folder's "スクリーンショット" (Screenshots) folder, the same default as the Windows Snipping Tool. The save locations can be changed, or opened in Explorer, from the settings window. Enable "保存時にファイル名を指定する" (choose a file name when saving) to pick the name and PNG or BMP format in a Save As dialog. Enable "録画の保存時にファイル名を指定する" (ask for a file name when saving a recording) to choose where a finished recording is saved; cancelling the dialog keeps it in the recording folder. Turn on "スクリーンショットに枠線を付ける" (add a border to screenshots) to draw a border, in the color and thickness chosen in settings, inside the edges of rectangle, window, and full-screen screenshots; freeform shapes get none. A capture delay of 3, 5, or 10 seconds hides the window before the toolbar appears. At least one destination must be enabled. Every capture is also kept in a history (the newest 50, 100, 200, or 500 as chosen in settings, stored in `%LOCALAPPDATA%\Snipping Lite\history`) that you can browse from the tray menu or the settings window: filter the gallery by date range or search it by date, open a screenshot to copy it again, save it as a file, show it in its folder, or delete it, and clear the whole history at once. "文字をコピー" (copy text) in an opened screenshot recognizes its text with the Windows text recognition and copies it to the clipboard; it needs a text recognition language for the text, which can be added in the Windows settings. In an opened screenshot, the pen and highlighter (five colors, three thicknesses, remembered between sessions) draw on the image Crop cuts it down, and "色の取得" (pick color) shows the color under the pointer and copies it as `#RRGGBB` when clicked; "変更を保存" (save changes) writes the result into the stored image, and Copy and Save as include it. Turn "スクリーンショットの履歴を残す" (keep a history of screenshots) off in settings to stop recording; screenshots can contain sensitive information, so clear the history when you no longer need it. A shortcut conflict is shown in the settings window. The app theme (follow Windows, light, or dark) can be chosen with "アプリ テーマ" (app theme) under "外観" (appearance) in settings. The interface is in Japanese only; the settings window follows the Windows Snipping Tool settings layout (sections, On/Off labels). All texts go through `src/i18n.rs`, where another language table can be added.

The toolbar and notification follow the Windows 11 Snipping Tool style, including the light or dark app theme. The settings window imitates the Windows 11 settings style (toggles, cards, the system theme, and the Mica backdrop on Windows 11 22H2 or later) but is not a pixel-exact copy; tooltips are not implemented, and annotation is only available for screenshots opened from the history. The outside of a freeform capture is transparent in PNG files and in applications that read transparency from the clipboard, and white elsewhere (including BMP files).
## Install

Replace `OWNER/REPO` with the GitHub repository once it exists.

```powershell
irm https://github.com/OWNER/REPO/releases/latest/download/install.ps1 | iex
```

The script downloads `snippinglite.exe` from the latest release, checks its SHA-256 and installs it to `%LOCALAPPDATA%\Programs\Snipping Lite`. To pick another folder, run `& ([scriptblock]::Create((irm <install.ps1 URL>))) -Directory <folder>`. Uninstall with `& "$env:LOCALAPPDATA\Programs\Snipping Lite\uninstall.ps1"`; your settings are kept.

A release is published by pushing a tag that matches the crate version, for example `v0.1.0`. `scripts/publish.ps1` builds the same files locally into `artifacts/`.
