# Snipping Lite

Snipping Lite は Windows ネイティブのスクリーンショットツールです。`pwsh -File scripts/run-latest.ps1` でリリース版を起動するか、`scripts/build.cmd` でデバッグ版を起動します。**Alt+Shift+S** を使うには起動したままにしてください。設定画面を閉じても通知領域に常駐します。トレイメニューから設定を開き直したり終了したりできます。

ツールバーで矩形、フリーフォーム、ウィンドウ、全画面を選択します。Escape でキャンセルします。設定からクリップボードへの自動コピーと `Pictures\Screenshots` への PNG 自動保存を選べます。「保存時にファイル名を指定する」を有効にすると、名前を付けて保存ダイアログで名前と PNG または BMP 形式を選べます。キャプチャの遅延（3、5、10 秒）を設定すると、ウィンドウを隠してからツールバーを表示します。少なくとも一方の保存先を有効にしてください。ショートカットが競合した場合は設定画面に表示します。

切り取りツールバーと設定画面は開発中で、Snipping Tool の細部までは再現できていません。画像への書き込みは未対応です。フリーフォームの範囲外は、PNG ファイルと透過を読み取れるアプリへのクリップボード貼り付けでは透明になり、それ以外（BMP を含む）では白になります。
