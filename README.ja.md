# Snipping Lite

Snipping Lite は Windows ネイティブのスクリーンショットツールです。アイコンは青い切り取り枠と赤青のはさみを組み合わせています。`pwsh -File scripts/run-latest.ps1` でリリース版を起動します。`scripts/build.cmd` はデバッグ版をビルドするだけで、起動はしません。起動時はウィンドウを開かず通知領域に常駐します。**Alt+Shift+S** を使うには起動したままにしてください。同時に動くのは 1 つだけで、起動中にもう一度起動すると、動いている方の設定画面を開きます。切り取り中、書き込み中、録画前のカウントダウン中は、もう一度起動しても、トレイメニューの「Snipping Lite」を選んでも画面を開きません。切り取りや書き込みの画面は前面に戻ってキーボードを受け取るので、Escape や Enter はそのまま効きます。設定はトレイメニューか撮影ツールバーの歯車から開けます。設定・履歴画面のタイトルバーは「Snipping Lite」と表示します。設定画面は別プロセス（egui 製）で開き、閉じても通知領域に常駐します。トレイメニューから設定を開き直したり終了したりできます。設定画面を開いている間は約 70 MB 使いますが、常駐するトレイ側は小さいままです。

切り取り中も画面はそのまま動き続け（動画やアプリが止まらず）、選択範囲の枠だけが描かれます。設定の「切り取り中に画面を暗くして静止する」をオンにすると、従来どおり画面が静止して暗くなります。画面上部のツールバーでスクリーンショットと録画を切り替え、画像・録画のどちらも、範囲のドロップダウンから矩形、フリーフォーム、ウィンドウ、全画面を選択できます。最後に選んだモードはアプリを終了するまで保持されます。Escape でキャンセルし、歯車ボタンから設定を開けます。ツールバーはボタン以外の部分をドラッグして移動でき、次に開くと上部中央に戻ります。設定の「撮影後もツールバーを表示したままにする」をオンにすると、撮影や録画のあともツールバーが画面に残り、そのボタンから次の撮影を始められます。× で閉じるまで、移動した位置に表示されます。ツールバーのビデオボタンは、選んだ範囲を MP4 ファイル（H.264、60 fps、マウスカーソルの有無を設定可能、音声は設定で選択（AAC））として ビデオフォルダーの「画面録画」フォルダー（標準の Snipping Tool と同じ既定の場所）に録画します。設定の「録画にマウスカーソルを含める」をオフにすると、カーソルを動画から除外できます。Snipping Tool と同じく、画面録画の「自動的に変更にコピー」は録画の MP4 ファイルをクリップボードに置き、エクスプローラーやチャットに貼り付けられます。「元の画面録画を自動的に保存する」をオフにすると、録画フォルダーには残さず、コピーしたファイルを貼り付けられるよう一時フォルダーに 1 日だけ置きます。2 つのうち少なくとも一方はオンにしてください。設定の「録画にマイク入力を含める」で既定のマイクを、「録画にシステム オーディオを含める」で PC から出る音を録画に入れられます。ウィンドウを録画するときは、そのウィンドウのアプリ（ブラウザの音声プロセスなど、起動した子プロセスを含む）の音だけを録音します。「ウィンドウ録画ではそのアプリの音だけを録音する」をオフにすると、システム全体の音を録音します。マイクなどを開けないときは、通知せずにその音を除いて録画します。実際のフレームレートは録画範囲と処理負荷によって変わります。ウィンドウ選択の画像・録画は対象ウィンドウ自体を取得し、手前に重なる別のウィンドウを含めません。録画は移動した対象にも追従します。録画の画素数は開始時に固定され、サイズを大きくすると切り抜き、小さくすると黒い余白になり、対象を閉じるか最小化すると録画を終了します。範囲で「ウィンドウ」を選んでクリックすると、そのウィンドウを録画できます（設定の「ウィンドウを録画するときタイトルバーを含めない」で、タイトルバーを除きます。既定はオンです）。フリーフォーム録画は選択した形を囲む矩形の動画になり、H.264 は透過に対応しないため形の外側は黒くなります。範囲を選ぶと 3、2、1 のカウントダウンが始まります（設定の「録画前にカウントダウンする」でオフにでき、カウントダウンをクリックするとキャンセルします）。範囲は赤い枠で示し、画面上部に経過時間の小さな表示が出ますが、どちらも動画には写りません。表示の「停止」を選ぶか、ショートカットをもう一度押すか、トレイアイコンをクリックするか、トレイメニューの「録画を停止」で終了し、通知からファイルを開けます。録画中も設定や履歴の画面は開けますが、録画する範囲に入ると、ほかのウィンドウと同じく動画に写ります。キャプチャ後は右下に通知が表示され（設定の「通知を表示する」をオフにすると、スクリーンショットと録画のどちらも通知しません）、「マークアップと共有」から履歴の編集画面で最新の画像を開き、履歴がオフの場合は「開く」から保存したファイルを開きます。ツールバーのペンのボタンは、Snipping Tool と同じくクイックマークアップのオン・オフを切り替えます。押しても画面は開かず、選んだ状態は次回も引き継ぎます。オンのときは、選んだ範囲が画面に残って下にバーが出ます。ペンや蛍光ペンで書き込み、消しゴムで線ごと消し、元に戻す・やり直す・すべて消去ができ、「キャプチャ」か Enter で、いつもどおりコピー、保存、履歴への記録をします。Escape か × で破棄します。書き込み中にトレイメニューから終了したときも破棄します。録画には使いません。履歴のボタンは履歴を開きます。設定からクリップボードへの自動コピーと ピクチャフォルダーの「スクリーンショット」フォルダー（標準の Snipping Tool と同じ既定の場所）への PNG 自動保存を選べます。「保存時にファイル名を指定する」を有効にすると、名前を付けて保存ダイアログで名前と PNG または BMP 形式を選べます。設定の「スクリーンショットに枠線を付ける」をオンにすると、矩形、ウィンドウ、全画面のスクリーンショットの外周の内側に、設定で選んだ色と太さの枠線を描きます（フリーフォームには付きません）。少なくとも一方の保存先を有効にしてください。撮影した画像は履歴（設定で選んだ最新 50・100・200・500 件、`%LOCALAPPDATA%\Snipping Lite\history` に保存）にも残り、トレイメニューか設定画面から見返せます。日付の範囲での絞り込みと日付の検索ができ、開いた画像は、再コピー、ファイルとして保存、フォルダで表示、削除ができ、履歴をまとめて消すこともできます。開いた画像の「文字をコピー」は、Windows の文字認識で画像内の文字を読み取ってクリップボードにコピーします。読み取る文字の言語は、Windows の設定で追加できます。開いた画像にはペンと蛍光ペン（5 色、3 段階の太さ。次回以降も記憶されます）で書き込めるほか、切り抜きもできます。「色の取得」では、指した位置の色を表示し、クリックすると `#RRGGBB` の形式でクリップボードにコピーします。「変更を保存」で結果を保存済みの画像に反映し、コピーと名前を付けて保存にも含まれます。設定の「スクリーンショットの履歴を残す」をオフにすると記録を止めます。スクリーンショットには機密情報が写ることがあるため、不要になった履歴は消してください。ショートカットが競合した場合は設定画面に表示します。保存先は設定画面から変更したりエクスプローラーで開いたりできます。アプリのテーマ（システム設定に従う、ライト、ダーク）は、設定の「外観」の「アプリ テーマ」で選べます。画面表示は日本語のみで、設定画面は Windows の Snipping Tool の設定と同じ構成（セクション分け、オン/オフ表示）です。文言は `src/i18n.rs` に集約してあり、別の言語の表を追加できます。

ツールバーと通知は Windows 11 の Snipping Tool に合わせたデザインで、アプリのライト・ダークテーマに従います。設定画面は Snipping Tool の設定に合わせています（トグル、カード、閉じた状態で始まる開閉式のカード、システムのテーマ、同じフォント（英数字は Segoe UI Variable、日本語は Yu Gothic UI）、Snipping Tool と同じ無地の背景）。ただしピクセル単位の完全再現ではなく、ツールチップは未対応です。設定、履歴、プレイヤーの画面は、UI Automation を通じてスクリーンリーダーなどの支援技術から操作できます。撮影ツールバー、マークアップのバー、通知はまだ対応していません。クイックマークアップはペン、蛍光ペン、消しゴムに対応し、Snipping Tool の図形、共有、テキスト アクションはありません。フリーフォームの範囲外は、PNG ファイルと透過を読み取れるアプリへのクリップボード貼り付けでは透明になり、それ以外（BMP を含む）では白になります。
## インストール

```powershell
irm https://github.com/valneko-twoon2/SnippingLite/releases/latest/download/install.ps1 | iex
```

現在のユーザー向けに（管理者権限なしで）`%LocalAppData%\Programs\Snipping Lite` へインストールし、ダウンロードの SHA-256 を確かめ、アプリを起動して、サインインのたびに起動するようにします。同じコマンドをもう一度実行すると更新できます。別のフォルダやリポジトリを使うときは、`install.ps1` をダウンロードして `-Directory <フォルダ>` や `-Repo <owner/name>` を付けて実行します。

削除するには、設定の「アプリ」を使います。設定と履歴は、インストール先の `uninstall.ps1` を `-RemoveData` 付きで実行しない限り残ります。保存したスクリーンショットと録画は削除されません。
リリースは、クレートのバージョンと同じタグ（例: `v0.1.0`）を push すると公開されます。同じファイルは `scripts/publish.ps1` でも `artifacts/` に作れます。
