# Snipping Lite

Snipping Lite は Windows ネイティブのスクリーンショットツールです。`pwsh -File scripts/run-latest.ps1` でリリース版を起動するか、`scripts/build.cmd` でデバッグ版を起動します。**Alt+Shift+S** を使うには起動したままにしてください。設定画面は別プロセス（egui 製）で開き、閉じても通知領域に常駐します。トレイメニューから設定を開き直したり終了したりできます。設定画面を開いている間は約 70 MB 使いますが、常駐するトレイ側は小さいままです。

切り取り中も画面はそのまま動き続け（動画やアプリが止まらず）、選択範囲の枠だけが描かれます。設定の「切り取り中に画面を暗くして静止する」をオンにすると、従来どおり画面が静止して暗くなります。画面上部のツールバーで矩形、フリーフォーム、ウィンドウ、全画面を選択します。最後に選んだモードはアプリを終了するまで保持されます。Escape でキャンセルし、ハンバーガーボタンから設定を開けます。ツールバーのビデオボタンは、選んだ矩形を MP4 ファイル（H.264、30 fps、マウスカーソル付き、音声なしの映像のみ）として ビデオフォルダーの「画面録画」フォルダー（標準の Snipping Tool と同じ既定の場所）に録画します。ドラッグの代わりにウィンドウをクリックすると、そのウィンドウを録画できます（設定の「ウィンドウを録画するときタイトルバーを含めない」で、タイトルバーを除きます。既定はオンです）。範囲を選ぶと 3、2、1 のカウントダウンが始まります（設定の「録画前にカウントダウンする」でオフにでき、カウントダウンをクリックするとキャンセルします）。範囲は赤い枠で示し、画面上部に経過時間の小さな表示が出ますが、どちらも動画には写りません。表示を選ぶか、ショートカットをもう一度押すか、トレイアイコンをクリックするか、トレイメニューの「録画を停止」で終了し、通知からファイルを開けます。キャプチャ後は右下に通知が表示され、選択すると保存したファイルを開き、ファイルに保存していないときは履歴の編集画面で最新の画像を開きます。設定からクリップボードへの自動コピーと ピクチャフォルダーの「スクリーンショット」フォルダー（標準の Snipping Tool と同じ既定の場所）への PNG 自動保存を選べます。「保存時にファイル名を指定する」を有効にすると、名前を付けて保存ダイアログで名前と PNG または BMP 形式を選べます。キャプチャの遅延（3、5、10 秒）を設定すると、ウィンドウを隠してからツールバーを表示します。少なくとも一方の保存先を有効にしてください。撮影した画像は履歴（設定で選んだ最新 50・100・200・500 件、`%LOCALAPPDATA%\Snipping Lite\history` に保存）にも残り、トレイメニューか設定画面から見返せます。日付の範囲での絞り込みと日付の検索ができ、開いた画像は、再コピー、ファイルとして保存、フォルダで表示、削除ができ、履歴をまとめて消すこともできます。開いた画像にはペンと蛍光ペン（5 色、3 段階の太さ。次回以降も記憶されます）で書き込めるほか、切り抜きもできます。「変更を保存」で結果を保存済みの画像に反映し、コピーと名前を付けて保存にも含まれます。設定の「スクリーンショットの履歴を残す」をオフにすると記録を止めます。スクリーンショットには機密情報が写ることがあるため、不要になった履歴は消してください。ショートカットが競合した場合は設定画面に表示します。保存先は設定画面から変更したりエクスプローラーで開いたりできます。画面表示は日本語のみで、設定画面は Windows の Snipping Tool の設定と同じ構成（セクション分け、オン/オフ表示）です。文言は `src/i18n.rs` に集約してあり、別の言語の表を追加できます。

ツールバーと通知は Windows 11 の Snipping Tool に合わせたデザインで、アプリのライト・ダークテーマに従います。設定画面は Windows 11 の設定アプリ風（トグル、カード、システムのテーマ、Windows 11 22H2 以降では Mica 背景）にしていますが、ピクセル単位の完全再現ではなく、ツールチップと音声の録音は未対応で、書き込みは履歴から開いた画像でのみ使えます。フリーフォームの範囲外は、PNG ファイルと透過を読み取れるアプリへのクリップボード貼り付けでは透明になり、それ以外（BMP を含む）では白になります。
