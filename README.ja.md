# Snipping Lite

Snipping Lite は Windows ネイティブのスクリーンショットツールです。`pwsh -File scripts/run-latest.ps1` でリリース版を起動するか、`scripts/build.cmd` でデバッグ版を起動します。**Alt+Shift+S** を使うには起動したままにしてください。設定画面は別プロセス（egui 製）で開き、閉じても通知領域に常駐します。トレイメニューから設定を開き直したり終了したりできます。設定画面を開いている間は約 70 MB 使いますが、常駐するトレイ側は小さいままです。

切り取り中は画面が静止して暗くなります。画面上部のツールバーで矩形、フリーフォーム、ウィンドウ、全画面を選択します。最後に選んだモードはアプリを終了するまで保持されます。Escape でキャンセルします。キャプチャ後は右下にプレビュー付きの通知が表示され、選択すると保存したファイルを開きます。設定からクリップボードへの自動コピーと `Pictures\Screenshots` への PNG 自動保存を選べます。「保存時にファイル名を指定する」を有効にすると、名前を付けて保存ダイアログで名前と PNG または BMP 形式を選べます。キャプチャの遅延（3、5、10 秒）を設定すると、ウィンドウを隠してからツールバーを表示します。少なくとも一方の保存先を有効にしてください。撮影した画像は履歴（設定で選んだ最新 50・100・200・500 件、`%LOCALAPPDATA%\Snipping Lite\history` に保存）にも残り、トレイメニューか設定画面から見返せます。日付の範囲での絞り込みと日付の検索ができ、開いた画像は、再コピー、ファイルとして保存、フォルダで表示、削除ができ、履歴をまとめて消すこともできます。開いた画像にはペンと蛍光ペンで書き込めます。「Save changes」で書き込みを保存済みの画像に反映し、コピーと名前を付けて保存にも含まれます。設定の「スクリーンショットの履歴を残す」をオフにすると記録を止めます。スクリーンショットには機密情報が写ることがあるため、不要になった履歴は消してください。ショートカットが競合した場合は設定画面に表示します。

ツールバーと通知は Windows 11 の Snipping Tool に合わせたデザインで、アプリのライト・ダークテーマに従います。設定画面は Windows 11 の設定アプリ風（トグル、カード、システムのテーマ、Windows 11 22H2 以降では Mica 背景）にしていますが、ピクセル単位の完全再現ではなく、ツールチップと画面録画は未対応で、書き込みは履歴から開いた画像でのみ使えます。フリーフォームの範囲外は、PNG ファイルと透過を読み取れるアプリへのクリップボード貼り付けでは透明になり、それ以外（BMP を含む）では白になります。
