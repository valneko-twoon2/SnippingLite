# Snipping Lite の動作仕様

README から移した、アプリの細かな動作の仕様です。テストのコメントは、期待する動作の根拠としてこの文書を参照します。

## 起動と常駐

- 起動時はウィンドウを開かず通知領域に常駐します。**Alt+Shift+S** を使うには起動したままにしてください。
- 同時に動くのは 1 つだけで、起動中にもう一度起動すると、動いている方の設定画面を開きます。
- 切り取り中、書き込み中、録画前のカウントダウン中は、もう一度起動しても、トレイメニューの「Snipping Lite」を選んでも画面を開きません。切り取りや書き込みの画面は前面に戻ってキーボードを受け取るので、Escape や Enter はそのまま効きます。
- 設定はトレイメニューか撮影ツールバーの歯車から開けます。設定・履歴画面のタイトルバーは「Snipping Lite」と表示します。
- 設定と履歴の画面は別プロセス（egui 製）で開き、閉じても通知領域に常駐します。トレイメニューから設定を開き直したり終了したりできます。
- 設定と履歴の画面は、閉じてもプロセスを終えずに隠して待たせ、次に開くときは表示し直すだけにします。初めて開くときはプロセスの起動と OpenGL の初期化を待ちますが、2 回目からはすぐに出ます。表示し直した設定画面は保存された設定を読み直し、履歴画面は一覧に戻ります。隠れたまま 10 分たつか、アプリを終了すると、そのプロセスは終わります。開いている間と隠れている間は 1 つあたり約 100 MB 使いますが、常駐するトレイ側は小さいままです。

## 切り取り

- 切り取り中も画面はそのまま動き続け（動画やアプリが止まらず）、選択範囲の枠だけが描かれます。設定の「切り取り中に画面を暗くして静止する」をオンにすると、従来どおり画面が静止して暗くなります。
- 画面上部のツールバーでスクリーンショットと録画を切り替え、範囲のドロップダウンから、画像は矩形、フリーフォーム、ウィンドウ、全画面を、録画は Snipping Tool と同じく矩形とウィンドウを選択できます（フリーフォームか全画面を選んだまま録画に切り替えると矩形になります）。最後に選んだモードはアプリを終了するまで保持されます。
- Escape でキャンセルし、歯車ボタンから設定を開けます。
- ツールバーはボタン以外の部分をドラッグして移動でき、次に開くと上部中央に戻ります。
- 設定の「撮影後もツールバーを表示したままにする」をオンにすると、撮影や録画のあともツールバーが画面に残り、そのボタンから次の撮影を始められます。× で閉じるまで、移動した位置に表示されます。
- ウィンドウ選択の画像は対象ウィンドウ自体を取得し、手前に重なる別のウィンドウを含めません。
- 設定の「スクリーンショットに枠線を付ける」をオンにすると、矩形、ウィンドウ、全画面のスクリーンショットの外周の内側に、設定で選んだ色と太さの枠線を描きます（フリーフォームには付きません）。
- 設定からクリップボードへの自動コピーと、ピクチャフォルダーの「スクリーンショット」フォルダー（標準の Snipping Tool と同じ既定の場所）への PNG 自動保存を選べます。少なくとも一方の保存先を有効にしてください。保存先は設定画面から変更したりエクスプローラーで開いたりできます。
- フリーフォームの範囲外は、PNG ファイルと透過を読み取れるアプリへのクリップボード貼り付けでは透明になり、それ以外（BMP を含む）では白になります。コピーはアルファ付きの 32 ビット DIB（CF_DIBV5）と、白の上に重ねたアルファなしの同じ画像（CF_DIB と CF_BITMAP）をクリップボードに置くため、透過を読まないアプリでも半透明の画素は濃くならず、白の上に重ねた色で見えます。

## 録画

- ツールバーのビデオボタンは、選んだ範囲を MP4 ファイル（H.264、60 fps、マウスカーソルの有無を設定可能、音声は設定で選択（AAC））として、ビデオフォルダーの「画面録画」フォルダー（標準の Snipping Tool と同じ既定の場所）に録画します。実際のフレームレートは録画範囲と処理負荷によって変わります。
- 設定の「録画にマウスカーソルを含める」をオフにすると、カーソルを動画から除外できます。
- Snipping Tool と同じく、画面録画の「自動的に変更にコピー」は録画の MP4 ファイルをクリップボードに置き、エクスプローラーやチャットに貼り付けられます。「元の画面録画を自動的に保存する」をオフにすると、録画フォルダーには残さず、コピーしたファイルを貼り付けられるよう一時フォルダーに 1 日だけ置きます。2 つのうち少なくとも一方はオンにしてください。
- 設定の「録画にマイク入力を含める」で既定のマイクを、「録画にシステム オーディオを含める」で PC から出る音を録画に入れられます。ウィンドウを録画するときは、そのウィンドウのアプリ（ブラウザの音声プロセスなど、起動した子プロセスを含む）の音だけを録音します。「ウィンドウ録画ではそのアプリの音だけを録音する」をオフにすると、システム全体の音を録音します。マイクなどを開けないときは、通知せずにその音を除いて録画します。
- 範囲で「ウィンドウ」を選んでクリックすると、そのウィンドウを録画できます（設定の「ウィンドウを録画するときタイトルバーを含めない」で、タイトルバーを除きます。既定はオンです）。手前に重なる別のウィンドウは含めず、移動した対象にも追従します。録画の画素数は開始時に固定され、サイズを大きくすると切り抜き、小さくすると黒い余白になり、対象を閉じるか最小化すると録画を終了します。
- 範囲を選ぶと 3、2、1 のカウントダウンが始まります（設定の「録画前にカウントダウンする」でオフにでき、カウントダウンをクリックするとキャンセルします）。
- 範囲は赤い枠で示し、画面上部に経過時間の小さな表示が出ますが、どちらも動画には写りません。表示の「停止」を選ぶか、ショートカットをもう一度押すか、トレイアイコンをクリックするか、トレイメニューの「録画を停止」で終了し、通知からファイルを開けます。
- 録画中も設定や履歴の画面は開けますが、録画する範囲に入ると、ほかのウィンドウと同じく動画に写ります。

## 書き込み（クイックマークアップ）

- ツールバーのペンのボタンは、Snipping Tool と同じくクイックマークアップのオン・オフを切り替えます。押しても画面は開かず、選んだ状態は次回も引き継ぎます。
- オンのときは、選んだ範囲が画面に残って下にバーが出ます。ペンや蛍光ペンで書き込み、消しゴムで線ごと消し、元に戻す・やり直す・すべて消去ができます。
- 「キャプチャ」か Enter で、いつもどおりコピー、保存、履歴への記録をします。そのとき描いている途中の線や、消しゴムでなぞっている途中の消去も、見えているとおりに含めます。
- Ctrl+C は、自動コピーの設定にかかわらずクリップボードにコピーしてから、同じように確定します（保存と履歴は設定どおり）。
- Escape か × で破棄します。書き込み中にトレイメニューから終了したときも破棄します。
- 録画と全画面のスクリーンショットには使いません。全画面は、ペンがオンでもその場で撮影します。
- Snipping Tool の図形、共有、テキスト アクションはありません。

## 文字の抽出

- ペンの右の文字のボタンは、Snipping Tool と同じく、選んだ範囲の文字を Windows の文字認識で読み取り、画像の代わりに文字をクリップボードにコピーします。
- ペンとは同時にオンにできず、アプリを起動するたびにオフに戻ります。録画には使いません。
- 文字を読み取る言語は、Windows の設定で追加できます。

## 通知

- キャプチャ後は右下に通知が表示されます（設定の「通知を表示する」をオフにすると、スクリーンショットと録画のどちらも通知しません）。
- 「マークアップと共有」から履歴の編集画面で最新の画像を開き、履歴がオフの場合は「開く」から保存したファイルを開きます。

## 履歴

- 撮影した画像は履歴（設定で選んだ最新 50・100・200・500 件、`%LOCALAPPDATA%\Snipping Lite\history` に保存）にも残り、ツールバーの履歴のボタン、トレイメニュー、設定画面から見返せます。
- 日付の範囲での絞り込みと日付の検索ができ、開いた画像は、再コピー、ファイルとして保存、フォルダで表示、削除ができ、履歴をまとめて消すこともできます。
- 開いた画像の「文字をコピー」は、Windows の文字認識で画像内の文字を読み取ってクリップボードにコピーします。
- 開いた画像にはペンと蛍光ペン（5 色、3 段階の太さ。次回以降も記憶されます）で書き込めるほか、切り抜きもできます。「色の取得」では、指した位置の色を表示し、クリックすると `#RRGGBB` の形式でクリップボードにコピーします。「変更を保存」で結果を保存済みの画像に反映し、コピーと名前を付けて保存にも含まれます。
- 設定の「スクリーンショットの履歴を残す」をオフにすると記録を止めます。スクリーンショットには機密情報が写ることがあるため、不要になった履歴は消してください。

## 設定と外観

- ショートカットが競合した場合は設定画面に表示します。
- アプリのテーマ（システム設定に従う、ライト、ダーク）は、設定の「外観」の「アプリ テーマ」で選べます。
- 画面表示は日本語のみです。文言は `src/i18n.rs` に集約してあり、別の言語の表を追加できます。
- ツールバーと通知は Windows 11 の Snipping Tool に合わせたデザインで、アプリのライト・ダークテーマに従います。設定画面は Snipping Tool の設定に合わせています（セクション分け、オン/オフ表示、トグル、カード、閉じた状態で始まる開閉式のカード、システムのテーマ、同じフォント（英数字は Segoe UI Variable、日本語は Yu Gothic UI）、Snipping Tool と同じ無地の背景）。ただしピクセル単位の完全再現ではなく、ツールチップはありません。
- ツールバーとマークアップのバーは、Snipping Tool と同じく、アイコンのボタンにマウスを置くと、少ししてボタンの下に名前を表示します。この表示はスクリーンショットにも録画にも写りません。
- 設定、履歴、プレイヤーの画面は、UI Automation を通じてスクリーンリーダーなどの支援技術から操作できます。撮影ツールバー、マークアップのバー、通知はまだ対応していません。

## マルチモニターと拡大率

- モニターはどう並べてもよく（主モニターの左や上の、負の座標のモニターを含む）、モニターごとに拡大率（DPI）が違ってもかまいません。
- ツールバー、マークアップのバー、カウントダウン、録画中の表示、通知は、それがあるモニターの拡大率で描きます。その拡大率が変わったとき、またはツールバーを拡大率の違うモニターへドラッグしたときは、新しい拡大率で描き直します。ツールバーは Windows が提案する位置に、ほかはいつもの場所（切り取った範囲の下、範囲の真ん中、上部中央、右下）に置きます。オーバーレイは画面を覆ったままで、切り取りは続きます。
- モニターの追加や取り外し、並びや解像度の変更があったときは、範囲を選んでいる切り取りを取り消します。静止した画像も、オーバーレイが覆う範囲も、画面と合わなくなるためです。書き込み中の切り取りは、描いた線ごと残し、バーを画面の中へ戻します。
- カウントダウンは取り消し、録画は止めていつもどおり保存します。ただし、どちらも録画する範囲の下のモニターが変わったときだけで、ほかのモニターの変更では続け、ウィンドウの録画はウィンドウを追いかけて続けます。
- 残したツールバーは、どのモニターにも載らない部分ができたときだけ、いちばん近いモニターの中へ移し、それ以外は動かした場所に置いたままにします。通知は新しい作業領域の右下へ移します。
- 設定、履歴、プレイヤーの画面（egui）は、拡大率の変更に自分で合わせます。

## ファイルの書き込みと異常終了

- スクリーンショット、履歴、録画は、末尾が `.partial` の一時名で書き、書き終えてから最後の名前にします。保存や録画の途中でアプリが止まっても（クラッシュやタスク マネージャーでの終了）、壊れたファイルが最後の名前で残ることはありません。
- 途中で止まって残った一時名のファイルは、次に同じフォルダーへ保存するとき（名前を付けて保存で選んだフォルダーも含みます。または履歴を消去するとき）に消えます。消すのは、もう動いていない Snipping Lite のプロセスが残したファイルだけなので、この PC のほかの Snipping Lite のウィンドウが保存している途中のファイルには触れません。
- ほかの PC や、Windows のほかのユーザーの Snipping Lite が動いているかは、この PC からは確かめられないので、ネットワーク上のフォルダーにあるものと、ほかのユーザーのもの（Public など、ユーザーの間で共有したフォルダーの中のもの）は、最後に書かれてから 5 分経ってから消します（この PC のフォルダーを共有して、ほかの PC から保存しているときは、この PC のフォルダーとして扱います）。
- 書き終えた録画が最後の名前にできないとき（ほかのアプリが同じ名前のファイルを開いているなど）は、`Snipping Lite 1 (2).mp4` のような空いている名前で残し、通知の設定にかかわらず、その場所を通知で知らせます。名前をまったく変えられないときは、その名前へ写して残します。写すこともできないときは、一時名のまま残し、その場所をエラーで知らせます。書き終えた録画は作り直せないので、一時名のままでも、次の保存で消えることはありません（保存しない録画の一時フォルダーでは、ほかの録画と同じく 1 日で消えます）。
- スクリーンショットは最後の名前にできなければ残さず、エラーを表示します。クリップボードへのコピーや履歴がオンなら、画像はそちらに残ります。
- 設定のファイル（`%APPDATA%\Snipping Lite` の `settings.ini`、`pen.ini`、`markup.ini`）も、同じく一時ファイルに書いてから名前を変えます。止まったアプリが残した一時ファイルは、次に Snipping Lite がそのファイルを読むときに消え、その中身は使いません。その前に保存した設定がそのまま効き、失われるのは止まる直前の変更だけです。
